## 2. Dados Pessoais Coletados

### 2.1. Dados fornecidos pelo usuário

| Dado | Finalidade | Base Legal (LGPD) |
|------|-----------|-------------------|
| Nome completo | Identificação e personalização | Execução de contrato (Art. 7º, V) |
| Endereço de e-mail | Comunicação e autenticação | Execução de contrato (Art. 7º, V) |
| Senha (quando aplicável) | Autenticação via e-mail/senha | Execução de contrato (Art. 7º, V) |
| Foto do perfil (quando via Google/Apple) | Personalização da experiência | Consentimento (Art. 7º, I) |

### 2.2. Dados coletados automaticamente

| Dado | Finalidade | Base Legal (LGPD) |
|------|-----------|-------------------|
| Identificador do dispositivo | Segurança e prevenção de fraude | Legítimo interesse (Art. 7º, IX) |
| Histórico de uso de cupons | Funcionamento do serviço (controle de limite mensal) | Execução de contrato (Art. 7º, V) |
| Data e hora de acesso | Segurança e auditoria | Legítimo interesse (Art. 7º, IX) |
| Dados de assinatura (status, tipo de plano) | Controle de acesso ao serviço | Execução de contrato (Art. 7º, V) |

### 2.3. Dados que NÃO coletamos

- Localização (GPS)
- Contatos do telefone
- Fotos ou arquivos do dispositivo
- Dados de cartão de crédito (processados exclusivamente pela Apple/Google)
- Dados biométricos

## 3. Como Utilizamos os Dados

Utilizamos seus dados pessoais exclusivamente para:

- **Autenticação e segurança** da sua conta.
- **Funcionamento do serviço**: controle de cupons, validação de assinatura, histórico de uso.
- **Comunicação**: notificações do app, atualizações de termos, suporte ao cliente.
- **Prevenção de fraude**: identificação de uso indevido (múltiplas contas, compartilhamento de cupons).
- **Melhoria do serviço**: análise agregada e anônima de uso do app.

**Não utilizamos seus dados para publicidade direcionada de terceiros.**

---

## 4. Compartilhamento de Dados

Compartilhamos dados pessoais apenas nas seguintes situações:

| Destinatário | Dados Compartilhados | Finalidade |
|---|---|---|
| **Google Firebase** (Google LLC) | Nome, e-mail, UID | Autenticação e banco de dados |
| **RevenueCat** (RevenueCat Inc.) | UID anônimo, status de assinatura | Gestão de assinaturas |
| **Apple / Google** | Dados de pagamento (processados por eles) | Cobrança de assinaturas |
| **Restaurantes parceiros** | Apenas confirmação de cupom válido (sem dados pessoais) | Validação do benefício |

Todos os fornecedores listados possuem políticas de privacidade próprias e comprometem-se com a proteção de dados.

**Não vendemos, alugamos ou cedemos seus dados pessoais a terceiros para fins comerciais.**

---

## 5. Armazenamento e Segurança

5.1. Os dados são armazenados no **Google Cloud Platform** (Firebase), com servidores na região da **América do Sul (São Paulo)**.

5.2. Medidas de segurança adotadas:
- **Criptografia em trânsito** (TLS/SSL) em todas as comunicações.
- **Criptografia em repouso** nos bancos de dados.
- **Regras de segurança** do Firestore que restringem acesso por usuário.
- **Autenticação segura** via provedores reconhecidos (Google, Apple) e hash de senhas pelo Firebase Auth.
- **Acesso restrito** aos dados por parte da equipe administrativa.

5.3. Os dados são retidos **enquanto sua conta estiver ativa**. Após a exclusão da conta, os dados são removidos em até **30 (trinta) dias**.

| **Anonimização ou bloqueio** | Solicitar anonimização de dados desnecessários |

## 7. Dados de Menores

O Passe do Sabor não é destinado a menores de **18 (dezoito) anos**. Não coletamos intencionalmente dados de menores. Caso identifiquemos dados de um menor, eles serão excluídos imediatamente.

## 8. Cookies e Tecnologias Similares

O aplicativo **não utiliza cookies**. Utilizamos apenas o armazenamento local do dispositivo (AsyncStorage) para preferências de tema e cache operacional, sem rastreamento.
